# 강의 문의 → 구글 시트 연결 (Apps Script)

사이트 문의 폼에서 보낸 내용을 구글 시트에 한 줄씩 쌓고,
내 이메일로 **'새 문의 도착'** 알림을, 신청자에게 **'문의가 접수되었습니다'** 자동 회신을 보냅니다.

시트 열 순서: **이름 / 이메일 / 전화번호 / 회사,직함 / 강의 문의 내용**

## 1. 시트와 스크립트 만들기

1. [구글 시트](https://sheets.new)에서 새 시트를 만들고 이름을 정합니다. (예: `강의 문의`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 [`Code.gs`](./Code.gs) 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 맨 위 **설정** 부분을 확인합니다.
   - `OWNER_EMAIL`: 알림을 받을 내 이메일 (기본값 `meshe921@gmail.com`)
   - `OWNER_NAME`: 자동 회신 메일에 보이는 이름
   - `SEND_AUTO_REPLY`: 자동 회신을 끄려면 `false`

## 2. 권한 허용 + 테스트

1. 위쪽 함수 선택 칸에서 **`testDoPost`** 를 고르고 **실행**을 누릅니다.
2. 권한 요청 창이 뜨면 내 구글 계정을 선택하고 허용합니다.
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동** 을 누릅니다. 내가 만든 스크립트라 안전합니다.
3. 시트에 **`문의`** 탭이 생기고 헤더와 테스트 한 줄이 들어갔는지 확인합니다.
4. `meshe921@gmail.com` 으로 메일 2통(새 문의 도착, 문의가 접수되었습니다)이 왔는지 확인합니다.
5. 확인이 끝나면 테스트 줄은 지워도 됩니다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 를 누릅니다.
2. 유형 선택(⚙️)에서 **웹 앱** 을 고릅니다.
3. 아래처럼 설정하고 **배포** 를 누릅니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 사이트에 연결

`src/data/site.js` 의 `inquiryForm.sheetUrl` 에 복사한 주소를 넣습니다.

```js
export const inquiryForm = {
  sheetUrl: 'https://script.google.com/macros/s/…/exec',
  ...
}
```

## 알아둘 점

- **코드를 고친 뒤에는** 배포 → 배포 관리 → ✏️ → 버전: **새 버전** 으로 다시 배포해야 반영됩니다. (URL은 그대로)
- 일반 Gmail 계정은 스크립트로 보내는 메일이 **하루 100통**까지입니다. 문의 1건에 2통(알림 + 자동 회신)을 쓰므로 하루 약 50건까지 처리됩니다.
- 주소를 브라우저로 열면 `{"ok":true,"message":"문의 접수 스크립트가 동작 중입니다."}` 가 보이면 정상입니다.
- `=`, `+`, `-`, `@` 로 시작하는 입력은 시트에서 수식으로 실행되지 않도록 앞에 `'` 를 붙여 저장합니다.
- 전화번호는 맨 앞 0 이 사라지지 않도록 글자로 저장합니다.

## 다른 곳에서 보낼 때 (POST 형식)

```
POST {웹 앱 URL}
Content-Type: text/plain   ← 브라우저에서는 이 형식이어야 바로 전송됩니다

{"name":"서미화","email":"meshe921@gmail.com","phone":"01021262533","company":"뷰티앤웰니스 AI 대표","message":"강의 문의 내용"}
```

응답: 성공 `{"ok":true}` · 실패 `{"ok":false,"error":"…"}`
`name`, `email` 은 필수입니다.
